# openkart

Jauns dizains [openkart.lv](https://openkart.lv) sākumlapai — autosporta / kartinga tēma.

Atver `index.html` pārlūkā. Saturs (jaunumi, kopvērtējums, kalendārs, partneri) pārņemts no esošās openkart.lv sākumlapas; saites ved uz openkart.lv.

- `index.html` — lapas struktūra
- `assets/css/style.css` — dizains (tumšā tēma, Openkart sarkanā, karogu raksti)
- `assets/js/main.js` — kopvērtējuma dati un cilnes, taimeris līdz startam, starta gaismas, mobilā izvēlne
